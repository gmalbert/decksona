SETUP, PLAYBACK & CONNECTIONS

Need a hand
getting in tune?

Quick answers for connecting Decksona, listening on your phone, and picking up playback after an interruption.

01

Phone audio stopped or did not resume

Phones require a tap to start or resume browser audio. Open Decksona and tap Listen on this phone or Resume phone audio. Decksona does not autoplay phone audio after the app opens or reloads.

On iPhone, iOS may pause web audio when the screen locks, the app goes to the background, or a call interrupts it. Return to Decksona and tap the resume control. Keep the app open while listening.

02

Decksona cannot connect to Music Assistant

Use Music Assistant’s direct server address, usually http://MUSIC_ASSISTANT_IP:8095 on a home network. A Home Assistant ingress URL is not a direct Music Assistant address.

Create the long-lived access token in Music Assistant → Settings → Profile. Long-lived access tokens created in Home Assistant will not work. Confirm that the phone or computer can reach the Music Assistant server on the same network.

03

A player says “Setup required”

Open Music Assistant and complete the requested setup for the Decksona player. Depending on the server’s access settings, choose guest or unpaired playback, or pair the player with the code Decksona displays.

04

The phone cannot open the web app

Make sure Home Assistant is serving the files from www/decksona, and open the full address http://HOME_ASSISTANT_IP:8123/local/decksona/index.html. The phone and server must be on a Wi-Fi network that allows devices to reach each other.

This home-network setup uses HTTP. Keep it on trusted local Wi-Fi; do not expose the address or Music Assistant token to the public internet.

05

The phone app still shows an older version

Copy the latest contents of the repository’s web/ folder over the existing Home Assistant www/decksona/ files, including the skins and audio bundle. Use Decksona’s Reload update notice if it appears. Reopening the Home Screen shortcut may still use cached files.

For full installation steps, browser limitations, and advanced phone-audio settings, see the phone app setup guide on GitHub ↗.

Still stuck? Open a GitHub issue ↗ and include your device, browser, and what you were doing when the problem happened. Never include your access token.
